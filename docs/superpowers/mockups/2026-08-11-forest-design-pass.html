02 — New compact card

The "glass button" species card

Small, roughly square, rounded corners, translucent instead of photo-backed — distinct from the big photo cards in Zoznam/Mapa on purpose. Rank badge is top-picks-specific; a plain library context would just drop it. Border and rank-badge tint shift into caution for non-edible species, same policy as everywhere else.

03 — Forest glyph set

Leaf · droplet · sunrise · spore

Thin-stroke line icons (1.6pt, rounded caps), same weight class as SF Symbols so they sit comfortably next to system glyphs — but drawn specifically for this app instead of generic. These four cover what's needed now; more get added the same way as they come up.

04 — Grain texture

Card fills, before and after

An SVG fractal-noise overlay at 5% opacity, blended with overlay — reads as a whisper of bark/leaf texture, not visible noise. Applied to forestMid/forestDeep fills only (cards, glass panels), never behind body text.

Before — flat gradient
After — 5% grain, overlay blend
05 — Display typeface

Fraunces, used only twice

This is a real embedded font, not a placeholder — Fraunces, open-source (SIL license), free to bundle in the app. It has a slightly organic, hand-cut character at display sizes without tipping into decorative. Body text, data, species names — everything else — stays on SF Pro exactly as it is today.
